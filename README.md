# Deadline

> **本项目由 AI 编写。** 代码、测试和文档都是在 AI 编程助手（Claude / Codex / DeepSeek Harness）的协助下生成的，人类负责提出需求、审核结果并在真实环境里验证。功能已在自己的账号上跑通，但**请自行判断是否可信**，重要数据务必保留备份。

本地优先的学业 Deadline 助手。数据只存在这台电脑的一个 SQLite 文件里，平时不联网、不调用 AI；只有编程网格同步会访问平台，且只读、只读你自己的课程页。

主要用途：把**编程网格的题集和截止时间**同步进来，加上手动录入和微信通知，统一成一份能提醒你的待办列表。

如果你也在用北大编程网格并受 Deadline 困扰，欢迎取用或参考；但请注意下面的**已知限制**，尤其是「拿不到完成状态」这一条。

## 能做什么

**编程网格同步**

- **一键同步**：程序打开自己的浏览器窗口，你登录一次，它读取课程页并列出变更预览，确认后写入。
- **手动导入 JSON**：备用方式，永远可用，不需要额外组件。
- 两者走同一条链路：**差异预览 → 逐条勾选 → 确认 → 写入 → 变更历史**。

**任务管理**

- 手动添加、编辑、标记完成 / 恢复、移入回收站 / 恢复。
- 按课程、类型、状态筛选；列表顶部显示**已过期 / 24 小时内 / 3 天内 / 待确认截止**四个数字。
- 自动识别重复和改期，但**只提建议，不自动覆盖**；改截止时间必须填原因并再次确认。
- 每条任务都有变更历史：原 / 新截止、原因、时间、来源。

**通知导入**

- 直接粘贴微信通知，本地扫描手机号、学号、身份证、姓名、邮箱、微信号、链接和各种凭据。
- 检测到凭据或无法消除的隐私风险时**阻断**，只给本地草稿让你改。
- 需要模型时可选 DeepSeek / MiMo；默认模拟，真实调用要你每次单独确认，并有每日费用上限。

**学校邮箱（只读）**

- 用你自己的校园网账号 + **客户端授权码**只读读取 INBOX 最近 7 天、最多 30 封；授权码默认只在本次运行的内存里，退出即失效。
- 本地规则给每封邮件分类（课程教务 / 学校通知 / 讲座 / 科研机会 / 竞赛 / 活动报名 / 普通资讯 / 广告 / 待确认），并标出重要程度，**每条判定都写明理由**。
- 「校园情报」看板可按分类、重要程度、时间和关键字筛选，并显示被筛掉了几封；低重要程度的邮件只是排在后面，不会消失。
- 自动提取报名 / 作业 / 材料提交等 **Deadline**；**活动举办时间只展示、不自动建任务**；缺年份或只有时刻的时间标为「待确认」，需要你自己填。
- 勾选并确认后才写入任务库，走的是和编程网格完全相同的去重、变更历史与提醒；**不会因为同步失败而删除任何已有任务**。
- 可以纠正分类和重要程度，修正会立即反映到看板上。AI 部分**只准备最小载荷、不发送**：正文与附件永远不进入载荷。

**提醒与备份**

- 独立进程每 60 秒检查，默认提前 3 天 / 1 天 / 3 小时弹 Windows 通知，档位可自定义。
- 同一档位只提醒一次；完成、删除、已过期的任务不再提醒。
- 升级数据库前自动备份，也可手动生成一致性快照。

## 安装

需要 Python 3.11+。

```powershell
git clone https://github.com/wangtongyue-pku/deadline.git
cd deadline
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
```

编程网格一键同步需要一个可选组件（约 39 MB）：

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[browser]"
```

它只装 `playwright` 这个包，**不会下载自带的 Chromium**——程序直接驱动你电脑上已经装好的 **Chrome**（没有 Chrome 就用 Edge）。想指定另一个浏览器：

```powershell
$env:PKU_BROWSER_CHANNEL = 'msedge'   # 可选值：chrome / msedge
```

## 启动

双击项目根目录的 **`start.bat`**：启动服务并自动打开 http://127.0.0.1:8502 ，用完关掉黑窗口即可。

也可以手敲：

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py --server.port 8502
```

服务是本机进程，**关掉窗口就打不开了**，所以是「先启动、再用网址」。改了代码要看到效果，必须重启服务（只刷新浏览器不够）。

## 用法

### 一键同步编程网格

1. 左侧选「**编程网格导入**」。
2. 填**课程编号**——课程页地址里 `/course/` 后面那 32 位十六进制。
3. 点「**立即同步**」，程序打开一个属于它自己的浏览器窗口。
4. **在这个窗口里你自己登录**（校园卡号 + 北大身份认证）。之前登录过通常会自动继续。
   > 登录期间请让窗口保持打开：程序最多等 5 分钟，只有确认你真的登录了才会继续。
   > 第一次用需要登录一次，之后登录状态保存在 `data/grid-session/chrome/`。
5. 程序读取课程页，显示：新题集 / 已有且无变化 / 截止时间变化 / 无法解析 各多少条。
6. 逐条核对，取消勾选要跳过的，给截止变化填原因，勾选确认后点「执行导入」。

### 手动导入（同步不可用时）

1. 在编程网格打开课程页，把地址末尾改成 `?type=json`。
2. 全选复制，存成 UTF-8 的 `.json` 文件（或浏览器「另存为」）。
3. 在页面上传，后面步骤与一键同步相同。

### 添加任务

左侧「手动待办」→ 展开「添加任务」→ 填标题、课程、类型、截止时间。只有日期没有明确时刻时，保存成「待确认」而不是猜一个 23:59。

### 通知导入

「通知隐私预览」用于查看脱敏结果和实际会发送的内容，纯本地模拟；「Deadline 智能解析」才会真正调用模型（需要 Key，默认关闭）。

### 学校邮箱

侧边栏选「学校邮箱」。**默认是演示模式**：读取内置的虚构邮件，不联网、不需要账号，可以先完整走一遍看板、筛选、Deadline 导入和反馈。

想读自己的邮箱时切到「真实邮箱（只读 IMAP）」：

1. 在页面里填校园网邮箱地址和**客户端授权码**（不是网页登录密码；在 mail.stu.pku.edu.cn 的设置里生成），勾选确认后点「保存到本次运行」。
2. 点「检查连接」确认能读到 INBOX，再点「同步邮件」。
3. 看板会列出邮件与分类理由；下方「Deadline 导入」逐条勾选，确认后写入本地任务库。

授权码只存在于这次运行的内存里：**关掉程序就没了**，不会写进任何文件、日志或交接文档；想彻底清掉点「断开连接」。真实邮箱这条路径**不做自动登录、不保存密码、不自动重登**，登录过期只会提示你重新输入。

登录被拒 / 网络不通 / 服务器返回异常内容分别是三种不同的提示，**都不会被当成「没有邮件」**。解析失败的邮件会记录 UID 并在下次同步自动重试。

### 提醒

另开一个 PowerShell 窗口，保持开着：

```powershell
# 先演练：不弹窗、不消耗提醒次数
.\.venv\Scripts\python.exe -m pku_deadline_agent.reminders --dry-run --once
# 正式运行
.\.venv\Scripts\python.exe -m pku_deadline_agent.reminders --notify
```

关机、休眠、关掉这个窗口或没登录桌面时不会弹窗；它也不会随开机启动。

## 一键同步的安全性

这是唯一会访问外部平台的路径，边界写得很死：

- **不读取你的密码。** 登录在它打开的窗口里由你完成，程序接触不到。
- **不读取你平时浏览器的数据。** 它用自己独立的配置目录，**不会碰你日常 Chrome 的 User Data**。代价是那个窗口里要单独登录一次。
- **不保存密码。** 只保留浏览器自己的登录状态；过期后只提示重新登录，**绝不自动重登**。
- **只读。** 只打开你有权查看的课程页；**不提交作业、不修改平台数据、不访问他人信息**。
- **不调用 AI。** 这条路径零 API 消耗。
- **不自动写入。** 取到数据先给你看预览，确认后才写库。

启动任何真实浏览器都需要代码里显式传 `allow_real=True`，测试和误调用都启动不了。

### 失败时你会看到明确的区别

| 情况 | 提示 |
| --- | --- |
| 登录过期 | 「需要登录（登录状态已失效）」→ 重新登录 |
| 网络不通 / 服务器 5xx | 「网络或服务端问题」→ 稍后重试 |
| 页面改版（返回的不是 JSON） | 「页面结构可能已改版」→ 这条路要改代码，手动导入仍可用 |
| 未安装可选组件 | 按钮禁用并提示安装命令 |
| 多门课有一门没读到 | **整批中止**，并列出是哪一门 |

**任何一种失败都不会删除、取消或完成你已有的任务。**

## 同步功能的保证

- **不会删除任务**：本次没出现的题集**不会**被删除、取消或标记完成。任务只能由你手动删除。
- **不会重复**：以平台题集 ID 为准，同一份数据同步两次，第二次全部显示「已有且无变化」。
- **不会误合并**：标题相同但平台 ID 不同的题集各自建任务；标题相似**绝不**自动合并。
- **数据不可信就不写**：只要有一条解析失败，**整批中止**并逐条报告原因，不做部分导入。
- **不碰你已有的任务**：只新增，或按你确认的条目改截止时间。

## 已知限制

- **拿不到完成状态**：编程网格的课程页响应里没有提交 / 通过 / 得分字段，所以导入的任务状态一律「未知」，**不会自动标记完成**，需要你自己勾。
- **一次一门课**：响应是单课程级的，有几门课就同步几次。
- **每日定时同步没做**：目前只能手动点。方案见 [同步方案评估](docs/stage6_sync_plan.md)。
- **提醒依赖桌面会话**：关机、休眠、未登录桌面时不会弹窗，也不保证你看到了。
- **没有登录认证**：服务只监听本机 `127.0.0.1`，不要暴露到公网或共享使用。SQLite 未加密。
- **隐私检测有误报漏报**：不能声称绝对安全，敏感内容仍需你自己核对。

## 数据与配置

数据库默认在 `data/deadlines.sqlite3`，首次运行自动创建。可以指定别的路径：

```powershell
$env:PKU_DATABASE_PATH = 'D:\某个目录\practice.sqlite3'
```

常用环境变量：

| 变量 | 用途 |
| --- | --- |
| `PKU_DATABASE_PATH` | 任务数据库位置 |
| `PKU_BROWSER_CHANNEL` | 同步用哪个浏览器（`chrome` / `msedge`） |
| `PKU_BROWSER_PROFILE` | 登录状态目录 |
| `PKU_AI_DAILY_LIMIT_CNY` | 模型调用的每日人民币上限 |
| `PKU_REAL_API_ENABLED` | 真实模型调用总开关（默认关闭） |
| `PKU_DEEPSEEK_API_KEY` / `PKU_MIMO_API_KEY` | 模型密钥；也可在「AI 设置」页保存到 Windows 凭据管理器（环境变量优先） |

`.env.example` 是配置模板，程序**不会**自动加载 `.env`。

### 配置与保存 API Key

打开侧边栏 **「AI 设置」**：

- 顶部显示每个提供方是否已配置，以及**来源**（环境变量 / Windows 凭据管理器）——只显示状态，**永远不显示 Key**。
- 选择提供方 → 在密码框粘贴 Key → 勾选确认 → 「保存到 Windows 凭据管理器」。DeepSeek 与 MiMo **分别管理**。
- 删除需要额外勾选确认；删除只作用于凭据管理器，**不会动你的环境变量**。
- 想存 Key 需要可选依赖 `keyring`（用 Windows 凭据管理器，不写明文文件）：

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[secrets]"
```

没装也能用——页面会说明原因并给出上面这条命令，此时用环境变量配置即可，功能不受影响。

**读取顺序**：环境变量 → Windows 凭据管理器 → 视为未配置。环境变量优先级最高，所以你原有的配置方式（包括 `start.bat` 里继承的变量）完全不变，也不会被页面上保存的值覆盖。

**边界**：Key 不写入 SQLite、配置文件、日志或交接文档；页面与错误信息都不回显 Key；凭据管理器以当前 Windows 账户加密（任何能以该账户运行的程序都能读取），数据库本身仍未加密。**保存 Key 不等于授权调用**：真实调用仍需 `PKU_REAL_API_ENABLED=1` 并在解析页逐次确认。

用量账本 `data/ai_usage.sqlite3` 与任务库同目录，记录调用日期、提供方、tokens、单价和费用，**不保存密钥、通知或响应正文**。

## 数据安全

- 任务库、账本、备份都在本机，**不要提交 Git、不要上传给 AI**。
- `.gitignore` 已排除密钥文件、数据库、备份、日志、虚拟环境和临时目录，但这不能替代提交前人工核对。
- 编程网格的登录状态在 `data/grid-session/`，已被忽略。想清除登录状态，删掉那个目录即可。
- 不要在任务里填密码、Cookie、Token 或私人聊天原文。

## 为什么不实现自动登录

编程网格的公开接口没能找到（`/help`、`/swagger-ui.html`、`/v2/api-docs` 均 404），唯一相关的开源 VS Code 扩展已归档停更，且**明文保存门户密码**。教学网的第三方工具 `pku3b` 同样**默认把密码明文写进配置文件**，作业 ID 还是本地哈希而非服务端 ID。

所以这个项目选择：**不做验证码识别、不保存密码、不批量抓取、不自动提交作业、不写回平台**。登录永远由你在它打开的窗口里完成。

调查过程与来源见 [可行性报告](docs/stage5_feasibility.md)。
