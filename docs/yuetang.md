# 北大问学·阅堂：作业 Deadline MVP

更新：2026-10-17（北京时间）。本模块只处理课程作业列表，不涉及考试、测试、答题、视频或定时同步。

## 日常使用

1. 正常启动 Deadline，侧栏选择「问学阅堂」。已有最近读取时直接显示，不必重新登录。
2. 确认本次读取范围后点击「读取问学阅堂」。默认一门课，最多 20 项、12 次向下滚动。
3. 在独立临时 Chrome / Edge 中本人完成统一认证、选择课程，打开作业列表。优先选择未完成（若有）；不要进入具体作业或测试。
4. 回到 Deadline，点击「列表已打开，开始读取」。完成后临时浏览器退出，清理本次 profile；最小化结果仅保存在本机忽略目录。
5. 核对课程、名称、截止和状态；缺字段可在「手动补充 / 修改任务信息」中修正，再应用补充。只写日期仍是截止时刻待确认，不补午夜。
6. 只勾选本次准备导入的作业，选择新增、人工关联或修改截止。没有默认关联目标；疑似重复仍需明确判断。状态未知可以新增本地待办，不表示平台未提交；本地完成状态独立管理。
7. 由本人勾选当次正式写入授权，核对拟执行操作，准备方案，再确认写入。部分读取还需确认「本次仅导入部分任务，并非完整同步」。程序先备份，再在事务内复核版本、迁移与保存。
8. 回「手动待办」查看任务。重启后仍保存在 SQLite；平台状态不自动修改本地完成状态。

首次正式入库请只选一条真实作业，由本人核对后点击确认。助手未代点授权或写入按钮。

## 复用与来源隔离

新增 `yuetang_reader.py` 和 `yuetang_validation.py`，复用智慧树的 `ReadTask` / `ScrollReport`、审核页、手动补充、差异匹配、事务入库和浏览器进程桥接；原智慧树界面 key 与行为保留。

来源为 `pku_yuetang`；载荷、最近结果和临时会话目录与智慧树隔离。JSON 只允许必要任务字段、覆盖统计、证据和经过安全校验的课程列表链接，不保存密码、Cookie、Token、隐藏状态或原始页面。结果须在进程退出、profile 清理完成后才进入审核。

平台专属扩展是 `yue_extension` v1 / `yue_source_links` / `yue_import_receipts`。核心 schema 仍为 v4；普通启动和预览不启用新扩展。用户确认写入后，在线备份 → BEGIN IMMEDIATE → 按需扩展来源 CHECK（保留已经启用的智慧树等来源）→ 快照 / revision 复核 → 任务 / 本地 UUID 关联 / 回执 → commit。异常整批回滚，包含 DDL。扩展版本未知时拒绝写入。

预览、人工目标选择和写事务都阻止智慧树与问学阅堂的任务直接跨平台关联 / 覆盖。重复提交同一批次返回原回执；重新读取的同名任务仍需人工选择关联或明确独立新增，不能假称标题是平台 ID。

## 读取失败与安全边界

页面结构、字段归属、课程上下文或节点顺序改变时停止；不从相邻卡片补字段。每帧先限定位置范围，最多 20 条再读取文本，双次观察校验稳定性。滚动仅当前列表祖先容器或文档；不翻页、不点击任务。虚拟节点替换 / 复用导致身份不确定时拒绝可信结果，不强行拼接。

用户未就绪前不读 DOM；等待最多 15 分钟。首次失败允许用户在同一临时会话中调整页面并明确重试一次；失败或取消不替换旧结果。退出只清理本次新建 profile，历史载荷、诊断、数据库和备份保留。不读取日常浏览器状态，不后台连接、不向 AI 上传数据。

这条路线降低凭据持久化与自动操作风险；用户授权不等于已经取得平台规则许可。实际使用仍需核对适用规则。
