## 日常流程

打开 Deadline → 侧栏「智慧树任务预览」→ 勾选本次读取范围 →「读取智慧树」→ 本人登录独立临时浏览器并打开一门课「作业 → 未完成」→ 返回 Deadline 点「列表已打开，开始读取」→ 自动展示结果 → 必要时手动补充 → 选新增 / 关联 / 改期 → 核对操作表 → 本人当次授权与确认写入 → 手动待办看板。

读取默认最多 5 项 / 12 次移动，界面可缩小；次数包含必要的回到顶部，最多 20 项是整次累计上限。每轮需重新勾选读取授权，范围改变也需重新确认。打开页面、勾选授权、打开浏览器都不会自动读取任务字段；最终读取要本人确认列表已打开。不要点击开始做题、考试、视频或提交。

浏览器从公开门户 `https://onlineweb.zhihuishu.com/` 开始，由本人登录并选择课程，不能用缺课程参数的作业子页代替登录入口，也不用向助手提供课程 ID。若本轮旧窗口仍是无参数子页，直接在该临时窗口打开门户、正常选课即可。程序等待时处理导航 / 新标签事件，但不读取任务字段。

## 离线已验证的改进

- 复用现有 `zhihuishu_real_read.py`，由 Streamlit 启动独立 Python 进程，避免 Windows 页面线程与 Playwright 生命周期混用；不引入依赖或新登录系统。
- 新 `BrowserRead` 只负责授权检查、独立目录、状态、就绪 / 取消信号和最小化结果交接。子进程环境白名单不传 API Key / 邮箱授权资料；标准输出不进入 UI。
- 仅读取精确获支持的列表路由；多个目标列表不自动择一。页面 / iframe 的非目标登录、视频、考试路由不做结构探针。
- `auto_container` 只在当前任务列表的祖先中找几何上可滚动的元素；唯一时使用它，没有则使用文档，有多个就报错。此为通用几何逻辑，不是新猜的真实平台选择器。普通 / 懒加载、位置受保护的虚拟列表仍复用原读取器。
- 同一卡片的位置保护、两次观察一致、逐字段可见性和累计上限保持。标题 / 截止选择器不随意放宽；实页提取率提升尚未验证，缺失可手动补充。
- 新读取 / 换来源清除旧手动修正与生产授权，防止行号复用；只改标题不会把原来明确的时刻变成日期待确认，清空日期则保持未知，未知状态不默认填未完成。
- 生产模式不要求额外模拟确认；原备份 / 扩展迁移 / 事务 / revision / 来源关联 / 幂等回执契约保持。

## 生命周期与本地资料

每次新建 `.local-tmp/zhs-sessions/<本地随机编号>/`，不复用日常浏览器或旧诊断目录。等操作者超过 15 分钟、主动取消、关闭窗口或读取结束都会退出；取消正处于有界读取时需等待该操作返回。清理仅限**本次创建的 profile**，失败会提示且不接收为成功；不会自动清理历史任务、历史载荷或备份。成功退出后才发布 `.local-tmp/zhs-current.json`，旧 `.local-tmp/zhs-validation/` 保留。最小化载荷仍含个人任务信息，但不含凭据、平台 ID、来源链接或页面全文。

页面离开或断开后，独立工作进程等待超时退出；这不是后台定时同步。不要把强制结束整个 Python / 系统进程当成正常退出；如崩溃残留登录目录，先核对对应窗口，再由用户决定清理，不能声称断电也能清理。现有 8510 历史实例与资料不由此流程关闭或删除。
