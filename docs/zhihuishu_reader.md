# 智慧树有界列表读取器（离线验证版本）

日期：2026-10-16。开发分支 `codex/zhihuishu-feasibility`。本轮仅读取与验证，不连接真实账号、不写 SQLite、不启动定时，也不增加尚不能使用的产品按钮。

## 交付与使用

- `zhihuishu_reader.py`：`BoundedTaskListReader`、显式 `ListProfile` 配置、标准化 `ReadTask`、`ReadReport` 与 `Coverage`；同名 / 改期的保守匹配建议 `possible_matches`。
- `zhihuishu_dom.py`：固定的同步 DOM 观察脚本，只读取白名单节点；配置值仅作为 CSS / 属性参数传入，不执行页面文字或配置中的代码。
- `tests/fixtures/zhihuishu_task_list.html`：重新构造的虚构 HTML，不是页面导出。只有卡片 / 时间容器和筛选类来自前次已授权核验；`fixture-*`、课程区域、标识、链接、总数和分页均为虚构设计。
- `tests/test_zhihuishu_reader.py`：用真实 Chrome DOM 引擎跑虚构页面，临时无头 context，阻断全部请求，不下载浏览器，不读日常 profile。

运行专项（项目根目录 PowerShell）：

```powershell
.\.venv\Scripts\python.exe -m pytest -o addopts='' -q tests/test_zhihuishu_reader.py
```

浏览器专项需要已获准安装的可选 Playwright 依赖和本机 Chrome / Edge；使用与网格相同的 `detect_channel()`，没有该可选依赖时浏览器测试显式跳过，不能将跳过称为通过。不能为了运行真实页面自行把 `real_verified` 改为 True；必须先取得授权并完成对应字段 / 范围的真实核验。

本机最终验证：**1059 项全量通过（51.89 秒）**，新增读取器 75 项，智慧树三个专项共 169 项；浏览器测试未跳过。`pip check` / `git diff --check` 通过。没有连接真实账号或修改用户数据库。

编程入口是 `BoundedTaskListReader(profile).read(page)`。`page` 是调用方已打开的 Playwright Page；读取器没有登录、导航或启动浏览器的代码，不调用网格专用 URL / JSON / 登录判断。调用方应在同一个拥有线程中使用同步 Playwright，并在结束后关闭临时 context / browser，禁止保存 storage state。此轮没有发布真实页面字段配置，也没有提供真实运行命令：默认仅允许 `about:blank` 的虚构页面；其他页面必须同时有具体真实读取授权（`allow_real=True`）和经过真实核验的完整配置。两个代码门槛都不能代替用户授权。

## 标准化数据与字段证据

`ReadTask` 是读取阶段的内存候选模型，刻意不伪造 `SourceRecord` 必需的稳定来源 ID。标题、课程、截止、日期-only、来源链接与观察到的三个 ID 默认不出现在 repr；不能把候选对象完整序列化进日志。状态仅来自再次验证的“作业 / 未完成”筛选，kind 固定为 homework，`opens_at=None`，不支持读取考试页或把任何开放时间当截止。

| 项目 | 模拟验证 | 真实证据 / 剩余条件 |
| --- | --- | --- |
| 标题与日期属于同一条任务 | 每张 `.homework-item` 内独立查询；嵌套卡片、字段重叠、多标题 / 多日期报错；缺首条标题不会挪用第二条 | 卡片 / 时间容器已见，标题叶节点仍未真实核验 |
| 课程绑定 | 列表必须属于唯一课程 scope；范围内唯一可见课程标题，卡片若声明另一课程则冲突；没有课程时保留 None 并阻断完整结论 | 课程标题 / 面包屑所在范围还未真实核验；不允许用户随手写课程名作为“平台字段” |
| 截止时间 | 北京时间、明确午夜、缺失、日期-only、非法 / 错误类别时间；只读独立时间节点，不扫描要求猜日期 | 前次屏内 2 个时间可解析；包含评论的时间容器需另核验日期叶节点，不靠正则截取整个卡片 |
| 状态 | 必须唯一激活作业 tab / 未完成 filter，切到考试或失去状态标记立即停止 | 前次已核验这两个选中标记；不从缺席、过期或按钮推断本地完成 |
| ID | 观察原字段而不认定稳定；缺失不造 ID，同批重复报冲突，Vue 编译属性 / 凭据属性禁止读取 | 未核验实际任务 / 课程 / 修读标识。两次同屏一致不等于跨刷新、排序或学期稳定 |
| 来源链接 | 仅指定字段的 href，允许本域 HTTPS、无认证参数的链接；无链接保留 None，危险链接拒绝且不打开 | 真实安全列表 / 任务链接尚未核验；本轮严格拒绝 query / fragment，不擅自剥除后保存错误链接 |
| 完整性 | 显示总数、已加载、屏内可见、读取、拒绝、屏外、最少未读数量及未读范围；分页 / 懒加载 / 虚拟列表 / 加载中使 view_complete=False | 真实总数、分页、懒加载、虚拟滚动、明确空态选择器仍未知；模拟特征不是平台已采用这些机制的证据 |

## 有界与一致性

最多 20 条**屏内可见卡片**。先数卡片，再读字段；21 条直接抛 `ReaderLimitExceeded` 并报告数量，不读取前 20 条后偷偷截断。屏外 / CSS 隐藏卡片只计数，不提取正文；已加载节点超过 1000 则停止。不自动滚动、翻页、点击、重试、请求 API 或读 iframe / storage / Cookie；无法取得内容即报错，不做整页正文 / HTML 兜底。

每次获取同一视图的两份有界观察，每份都在单次同步 JS 中逐卡片提取。期间若发生跳转、字段 / 数量 / 课程 / 筛选变化，结果作废；页面报错只给固定说明，不回显可能含认证资料的外部异常。两次一致只能证明受检时间点一致，无法保证以后不变化，也不能排除未知网站自身副作用。

`Coverage.view_complete` 只表示**当前已配置的列表视图**：有可解析总数、全部已读、无未读 / 加载 / 虚拟化提示且字段无错误。它不证明“整门课程所有任务”或“平台没有其他任务”。缺截止时保留未知并列出问题，不能把失效的时间选择器算作成功。零记录只有在明确空态 + 显示总数零 + 已加载零 + 无其他问题时才 `confirmed_empty=True`。无论这些标记为何值，`ready_for_sync` 当前始终 False，`require_sync_ready()` 始终拒绝，防止后续调用方误用结果直接写库。

## 缺可靠 ID 的保守匹配

`possible_matches` 只对规范化课程 + 标题 + 种类提出可能重复 / 改期的位置列表，不以日期或行号作为身份；所有同名候选都保留。同名任务不合并，发现日期变化也不覆盖。没有课程则不提出跨课匹配。输出的位置仅用于本次人工审核，不能保存成平台 ID。即使 DOM 提供 ID，此轮仍 `identity_verified=False`；跨刷新 / 重排 / 不同课程与修读范围的稳定性须后续单独验证。

## 到一键同步的剩余工作

1. 另行说明范围并取得真实核验授权：本人登录，一门课 / 一个列表，≤20 条可见项，只读取节点结构与必要字段，不进任务、不翻页、不保存认证状态、不调用 AI、不写任务库。授权不能从这份离线实现推导。
2. 核验标题 / 日期叶节点、课程可见上下文与 ID 属性；仅在已授权范围内比较字段归属。若同屏无法判定 ID 稳定性或分页到底，记录未知，不擅自刷新 / 重排 / 扩课。
3. 验证总数、加载 / 空态、分页与虚拟化的真实表现，并建立证据清晰的真实配置；页面结构变化停止，避免漏项。
4. 再单独实现和测试审核入库：source / 元数据安全迁移与在线备份、稳定身份或人工保守匹配、改期预览 / revision / 历史、链接与独立时间语义保存。此轮不实施。
5. 后续授权多课选择与读取，任一课失败整批停止；真实联调通过后才展示可用的一键同步入口。后台定时不在本轮范围。
